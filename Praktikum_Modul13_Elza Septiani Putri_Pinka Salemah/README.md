# Student Reminder App

## Deskripsi
Student Reminder App adalah program sederhana berbasis Python
untuk membantu mahasiswa mengingat tugas dan tanggal deadline.

## Tujuan
- Mengingatkan mahasiswa tentang tugas.
- Menampilkan tanggal deadline.
- Menghitung sisa hari sebelum deadline.

## Teknologi
- Python 3
- Google Colab
- GitHub

## Cara Menjalankan
Jalankan file student_reminder.py menggunakan Python.

## Anggota Kelompok
- Anggota 1: Isi nama
- Anggota 2: Isi nama

## Fitur
- Input nama mahasiswa.
- Input nama tugas.
- Input tanggal deadline.
- Menghitung sisa hari deadline.
- Menampilkan pesan pengingat.
